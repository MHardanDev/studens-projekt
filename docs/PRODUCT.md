# المنتج والمتطلبات

## الهدف

منصة عربية مستقلة تساعد الطلاب في سوريا على إيجاد ملخصات وملاحظات دراسية يملكها أصحابها أو لديهم إذن بنشرها. البحث والقراءة والتنزيل مجانيان، والحساب مطلوب فقط للمفضلة وطلبات المحتوى والمساهمة.

## نطاق النسخة الأولى

- محتوى تجريبي محدود: سنة واحدة وفصل واحد ضمن كلية واحدة عند البداية.
- نموذج البيانات يجب أن يستوعب جامعات وكليات وخططاً وسنوات وفصولاً ومواداً متعددة دون أرقام جامدة.
- بيانات المرحلة 2 التجريبية الحالية: جامعة تشرين، كلية الاقتصاد، برنامج اقتصاد، أربع سنوات، فصلان لكل سنة، وثلاث مواد تجريبية فقط مع ملفات وصفية بلا PDF.
- موقع ويب خفيف يعمل من المتصفح، لا تطبيق Android.
- الرفع للمساهمين المعتمدين فقط، والمراجعة تسبق النشر دائماً.
- الإعلانات مؤجلة ومعطلة افتراضياً، ولا ترتبط مجانية الملفات بقبول AdSense أو أي دخل.

## خارج النسخة الأولى

تطبيق Android، دردشة، شبكة اجتماعية، تعليقات مفتوحة، فيديو، OCR شامل، مساعد AI، بيع ملفات، اشتراكات، نظام نقاط قابل للصرف، وشراكات مكتبات آلية.

## الأدوار

- زائر: يبحث، يقرأ صفحات المحتوى المنشور، وينزل الملفات المنشورة بلا حساب.
- Student: مستخدم عادي، يستخدم لاحقاً المفضلة وطلبات المحتوى.
- TrustedContributor: يستطيع لاحقاً رفع ملفات ضمن نطاق مصرح به، ولا ينشر بنفسه.
- FacultyModerator: يراجع لاحقاً ضمن نطاق كلية أو برنامج، ولا يساوي superuser.
- SiteAdmin: يدير الدعوات والنطاقات داخل الإدارة.

## الصفحات الأساسية

- الرئيسية: بحث واختيار الجامعة والكلية والسنة والفصل.
- الكلية والخطة: سنوات وفصول متاحة دون افتراض أعداد ثابتة.
- المادة: وصف أصلي وقائمة ملفات منشورة.
- نتائج البحث: نتائج عربية وفلاتر وروابط قابلة للمشاركة.
- الملف: عنوان ومصدر وإصدار وحجم وصفحات وتاريخ وتنزيل ومعاينة بطلب المستخدم.
- مكتبتي: مفضلة وروابط متابعة للحساب.
- طلب مادة: طلب ملف ناقص مع منع التكرار.
- المساهمة: طلب اعتماد ورفع للمساهم المعتمد.
- الإشراف: مراجعة الإصدارات والبلاغات والطلبات ضمن الصلاحية.
- الإدارة: الفهرس والمستخدمون والصلاحيات ومؤشرات التشغيل.
- صفحات الثقة: عن المبادرة، التواصل، الخصوصية، الاستخدام، حقوق المحتوى والاعتراض.

## متطلبات القبول

- REQ-001: البحث والقراءة والتنزيل للمحتوى المنشور متاحة للزائر دون حساب.
- REQ-002: الحساب مطلوب فقط للمفضلة وطلبات المحتوى والمساهمة.
- REQ-003: الواجهة عربية RTL أصلية، والنصوص والتصميم من إنشاء المشروع.
- REQ-004: الوظائف الأساسية تعمل دون JavaScript عبر روابط ونماذج HTML.
- REQ-005: العرض يدعم 320 و360 و390 و412 و768 و1280 بكسل بلا تمرير أفقي.
- REQ-006: أول تحميل للصفحات العامة الأساسية لا يتجاوز 150 KiB مضغوطة، باستثناء PDF أو المعاينة المطلوبة صراحة.
- REQ-007: JavaScript في المسار الأولي لا يتجاوز 35 KiB مضغوطاً، وCSS لا يتجاوز 30 KiB مضغوطاً.
- REQ-008: لا تحميل تلقائي لملفات PDF أو معاينات أو إعلانات عند فتح الصفحات العامة.
- REQ-009: الرفع محصور بمساهم معتمد وضمن نطاق مصرح به.
- REQ-010: الرفع لا ينشر الملف تلقائياً.
- REQ-011: النشر يتطلب فحصاً ناجحاً ومراجعة حقوق ومراجعة تنظيمية.
- REQ-012: اعتماد المساهم لا يعني شهادة صحة علمية للمحتوى.
- REQ-013: الصلاحيات تتحقق على الخادم لكل كائن وعملية، بما فيها HEAD وRange والمعاينات وأدلة الحقوق.
- REQ-014: التخزين الخاص والحسابات وقاعدة البيانات حقيقية، ولا يستخدم localStorage كنظام بيانات أو صلاحيات.
- REQ-015: كل إصدار ملف يحتفظ بميتاداتا وبصمة وتاريخ وحالة مستقلة.
- REQ-016: الحجب يعلو كل حالات النشر ويمنع الظهور والتحميل والمعاينات الجديدة.
- REQ-017: البيانات التجريبية موسومة بوضوح ولا تعرض كخطة رسمية أو أرقام استخدام حقيقية.
- REQ-018: لا تفعيل لخدمات مدفوعة أو إعلانات أو رسائل حقيقية أو نشر عام دون موافقة صريحة.
- REQ-019: لا تخفيف لمعايير القبول أو حذف اختبارات لتجاوز فشل.
- REQ-020: كل مرحلة تسجل نتائجها واختباراتها وعوائقها في سجل التقدم.
- REQ-021: الهيكل الدراسي يدار من قاعدة البيانات ولا يفترض عدداً ثابتاً للسنوات أو الفصول أو المواد.
- REQ-022: صفحة التصفح العامة تعرض الجامعات والكليات والبرامج والسنوات والفصول والمواد من قاعدة البيانات.
- REQ-023: ملفات المرحلة 2 وصفية فقط ولا تحتوي رفع PDF أو تخزين ملفات حقيقي.
- REQ-024: seed التجريبي قابل لإعادة التشغيل دون تكرار، وبياناته موسومة كتجريبية.
- REQ-025: الصفحة الرئيسية توفر بحثاً سريعاً ووصولاً مباشراً للتصفح ومحتوى فعلياً من قاعدة البيانات عندما يتوفر.
- REQ-026: البحث العام يعمل عبر GET دون JavaScript ويحافظ على نص البحث بعد الإرسال.
- REQ-027: البحث المبدئي يشمل أسماء المواد ورموزها وعناوين الملفات الدراسية المعتمدة.
- REQ-028: صفحة التصفح تعرض الملفات التجريبية المرتبطة بالمادة دون تحميل PDF أو معاينات.
- REQ-029: مبدل اللغة يظهر روابط عربية وإنكليزية وألمانية ولا يكسر مسارات `/ar/`, `/en/`, و`/de/`.
- REQ-030: تسجيل الدخول والخروج يعملان بصفحات Django server-rendered خفيفة وPOST للخروج.
- REQ-031: الصفحات العامة `/ar/` و`/ar/browse/` تبقى متاحة للزائر دون حساب.
- REQ-032: أدوار المنصة لا تمنح `superuser` تلقائياً.
- REQ-033: مساهم موثوق لا يملك صلاحية نشر الملفات بنفسه.
- REQ-034: نطاقات المساهمين والمشرفين تحدد جامعة أو كلية أو برنامجاً أو مادة، ولا تكون عامة على الموقع كله افتراضياً.
- REQ-035: الدعوات single-use، لها token عشوائي آمن، تاريخ انتهاء، وحالات واضحة.
- REQ-036: لا يرسل النظام بريداً حقيقياً للدعوات في المرحلة 4؛ يظهر الرابط في الإدارة فقط.
- REQ-037: صفحة رفع PDF متاحة للمساهم الموثوق فقط، وتعمل دون JavaScript.
- REQ-038: المساهم لا يرفع إلا ضمن `ContributorScope` مطابق للمادة/البرنامج/الكلية/الجامعة.
- REQ-039: الرفع يقبل PDF فقط بحد 20 MiB ويتحقق من الامتداد ونوع المحتوى وتوقيع البايتات.
- REQ-040: الملفات المرفوعة تخزن في مساحة خاصة غير static/public وباسم داخلي آمن.
- REQ-041: الملف المرفوع يبدأ `uploaded_pending_scan` و`scan_status=pending` ولا ينشر تلقائياً.
- REQ-042: لا يظهر الملف المرفوع كرابط تحميل أو كملف عام قبل نجاح الفحص والمراجعة.
- REQ-043: عند غياب antivirus/worker فعلي، يبقى النظام fail-closed ولا يعد الفحص ناجحاً.
- REQ-044: لا ينتقل الملف إلى `pending_review` إلا إذا كانت `scan_status=clean`.
- REQ-045: الاعتماد لا يتم إلا من `FacultyModerator` أو `SiteAdmin` ضمن `ModeratorScope` مطابق.
- REQ-046: `TrustedContributor` لا يستطيع اعتماد ملفه أو نشره، والمشرف لا يراجع ملفاً رفعه بنفسه.
- REQ-047: كل اعتماد ينشئ `DocumentVersion` ثابتة، والظهور العام يتطلب نسخة منشورة معتمدة.
- REQ-048: رفع نسخة أو ملف جديد لا يحذف النسخة المنشورة القديمة قبل مراجعة جديدة.
- REQ-049: صفحة المراجعة تعمل server-rendered وPOST محمي بـCSRF للاعتماد والرفض.
- REQ-050: الرفض يتطلب سبباً مختصراً محفوظاً.
- REQ-051: البلاغات متاحة للزائر أو الطالب على الملفات المنشورة فقط.
- REQ-052: التنزيل العام محصور بوثيقة `approved + clean` لها `DocumentVersion` منشورة وملف داخلي موجود.
- REQ-053: صفحة الملف العامة تعرض metadata من النسخة المنشورة الثابتة مع رابط تنزيل ورابط بلاغ.
- REQ-054: تنزيل PDF يمر عبر endpoint خادمي ولا يقدم `MEDIA_ROOT` أو مسار التخزين الخاص مباشرة.
- REQ-055: endpoint التنزيل يدعم `GET`, `HEAD`, نطاق بايتات واحد، و`If-Range` مع `206` و`416` حسب صحة النطاق.
- REQ-056: استجابة التنزيل ترسل `Content-Length`, `Accept-Ranges`, `ETag`, و`Content-Disposition` وتبث الملف دون تحميله كاملاً في الذاكرة.
- REQ-057: وضع توفير البيانات يعمل دون JavaScript ويحفظ اختياراً غير حساس في كوكي محدود العمر.
- REQ-058: لا تحمل الصفحة العامة PDF أو معاينة تلقائياً، سواء كان وضع توفير البيانات مفعلاً أم لا.
- REQ-059: يمكن للرئيسية استئناف آخر ملف أو تصفح أو بحث عبر مسار داخلي محدود لا يحتوي توكنات أو بيانات جلسة.
- REQ-060: الملفات `pending`, `rejected`, `uploaded_pending_scan`, أو غير النظيفة لا تظهر في التصفح ولا تفتح أو تنزل للعامة.
- REQ-061: لا يستخدم `localStorage` للجلسات أو التوكنات أو تفضيلات المرحلة 7.
